# 学习陪伴模式 · 设计文档 v1

状态：2026-11-11 设计，Chris 确认。目标人群：孩子（小学/初中）。核心场景：改善坐姿和学习习惯。

## 0. 目标与边界

**做什么**：陪孩子学习，定时提醒休息、坐姿提醒、主动鼓励，自动记录学习时长。
**不做什么**：不判断学得好不好、不监控内容、不替代家长。

**三条红线（来自产品三铁律）**：
1. 孩子知情且可关：开启要她说/按，界面常显状态，她随时能关。
2. 画面不落盘、不上云：只在内存跑检测，输出只有"在/不在/坐姿"几个数字。
3. 主动开口有预算：固定话术不走 LLM，每小时最多 N 次。

## 1. 三阶段路线

| 阶段 | 能力 | 交付物 |
|---|---|---|
| 0（本次） | 计时器 + 主动提醒 | 孩子说"开始学习"→ 40 分钟后主动提醒休息，可对话顺延 |
| 1 | 本地视觉感知 | 摄像头 1fps 检测"人在座位"，自动暂停/续计时 |
| 2 | 坐姿/姿态 | 距离过近、趴桌提醒；扩展：运动动作分析（后期） |

## 2. 第 0 期：学习计时与主动提醒

### 状态机

```
[空闲] --"开始学习"--> [学习中] --到40分钟--> [提醒休息(主动播报)] --"好的"--> [休息中]
                            ↑                                                    |
                            |------------------------"再给我5分钟"---------------+
                            |
[休息中] --到5分钟--> [提醒回来(主动播报)] --"回来了"--> [学习中]
```

### 数据结构

新表 `study_sessions`：
```sql
CREATE TABLE study_sessions (
  id INTEGER PRIMARY KEY,
  person_id INTEGER NOT NULL,
  started_at TEXT NOT NULL,
  ended_at TEXT,
  study_seconds INTEGER DEFAULT 0,
  break_seconds INTEGER DEFAULT 0,
  status TEXT DEFAULT 'active' -- active/paused/completed
);
```

新表 `study_events`（可选，用于后期分析）：
```sql
CREATE TABLE study_events (
  id INTEGER PRIMARY KEY,
  session_id INTEGER NOT NULL,
  event_type TEXT NOT NULL, -- start/break/resume/end/reminder/posture
  event_data TEXT,
  created_at TEXT NOT NULL
);
```

### 配置项（.env）

```
ROBOT_STUDY_ENABLED=true              # 总开关，默认 false
ROBOT_STUDY_FOCUS_MINUTES=40          # 专注时长（分钟）
ROBOT_STUDY_BREAK_MINUTES=5           # 休息时长（分钟）
ROBOT_STUDY_MAX_REMINDERS_PER_HOUR=6  # 主动开口上限
```

### 话术表

| 触发 | 机器人说（固定，不走 LLM） | 孩子可能回 | Agent 判断逻辑 |
|---|---|---|---|
| 专注到 40min | "学了 40 分钟了，起来活动 5 分钟吧。" | - | 自动进休息状态 |
| 孩子回话 | - | "再给我 5 分钟" | Agent 提取延时数字，顺延；未提取到数字则按 5 分钟 |
| 休息到 5min | "休息够了，继续加油吧！" | - | 自动回学习状态 |
| 孩子说结束 | "今天学了 1 小时 20 分，休息了 2 次，辛苦了！" | - | 结束本次 session |

### 接口设计

- `POST /api/study/start`：开始学习（需 person_id + 身份校验）
- `POST /api/study/pause`：暂停（手动休息）
- `POST /api/study/resume`：继续
- `POST /api/study/end`：结束本次
- `GET /api/study/current`：当前状态（包含倒计时）
- Agent 工具：`study_extend(minutes)` 延长当前阶段

### 页面交互（最简）

"陪伴"页底部新增学习卡片：
```
┌─────────────────────────────────────┐
│ 学习陪伴 · 未开始                      │
│ [开始学习]                             │
└─────────────────────────────────────┘

开启后：
┌─────────────────────────────────────┐
│ 学习中 · 已专注 23 分钟                │
│ 离下次休息还有 17 分钟                  │
│ [暂停] [结束]                         │
└─────────────────────────────────────┘
```

### 第 0 期不做
- 摄像头（手动计时即可）
- 视觉检测
- 家长报告

## 3. 第 1 期：加入本地视觉感知

- 学习模式下摄像头常开（页面明确指示"陪伴中，摄像头使用中"）
- 本地 1 帧/秒运行人脸/人形检测（OpenCV / MediaPipe）
- 检测结果：在座 / 离座，自动暂停/续计时
- **隐私**：帧不存、不传、不上云；检测模型本地运行

## 4. 第 2 期：坐姿与姿态

- 距离过近（人脸框占比 > 阈值）→ 提醒"离屏幕远一点"
- 趴桌（姿态关键点，需 MediaPipe Pose 或类似）
- 扩展方向（后期）：运动动作分析（深蹲、俯卧撑标准度）

## 5. 技术栈选择

| 模块 | 方案 | 依据 |
|---|---|---|
| 状态机 | Python 服务端计时器 + 事件记录 | 复用 reminder_loop 模式 |
| 主动播报 | 复用 `voice.speak()`，固定话术不走 LLM | 可靠、零延迟 |
| 对话顺延 | Agent 工具 `study_extend(minutes)` | 复用现有 Harness 桥接 |
| 视觉检测 | OpenCV 人脸检测（已有）+ MediaPipe Pose（待加） | 本地、开源、CPU 可跑 |

## 6. 代码组织

```
  study_tools.py    # Agent 工具：extend/pause/resume/end

  config.py         # ROBOT_STUDY_* 配置

tests/

```

开关：`ROBOT_STUDY_ENABLED=false` 时，`/api/study/*` 返回 503，学习循环不启动。

## 7. 第 0 期验收标准（本次交付）

- [ ] 孩子说"开始学习"（或点按钮）能成功进入学习状态

- [ ] 休息倒计时到 5 分钟主动提醒回来

- [ ] 结束时播报总时长摘要
- [ ] 页面卡片实时显示当前状态和倒计时

**隐私承诺（写给孩子的话）**：
机器人陪你学习时，摄像头只看"你在不在座位上"，看完就忘，不录像、不保存、不发到网上。你随时能关掉它，爸爸妈妈只会看到"学了多久"这个数字，不会看到画面。
